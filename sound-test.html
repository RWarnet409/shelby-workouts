Sound test for the ⏱ ding · round 2

Which way of making a sound works on this phone: with the ring/silent switch on silent, and without stopping the music.

How to run it
  1. Start music in Spotify (AirPods or speaker). Put the phone in silent mode.
  2. Reload this page before every button. Each button starts the sound engine fresh, but a reload keeps Safari from carrying anything over.
  3. Tap a button. It should sound twice: right away, and again 5 seconds later (the second one is what the ⏱ clock would do). Keep this page on screen for those 5 seconds.
  4. Note for each: heard it? Did Spotify keep going, dip for a moment, or stop?
  5. When done, screenshot the log at the bottom (it includes the "This phone" line).
